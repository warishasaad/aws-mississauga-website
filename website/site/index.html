About the community

A room full of people building on AWS

Starter guide

What is AWS?

Amazon Web Services rents you computing power, storage, databases and AI over the internet, so you pay for what you use instead of buying servers. Here's how to start.

  1. Learn the basicsTake the free Cloud Practitioner Essentials course on Skill Builder.
  2. Create an accountSign up for the Free Tier and set a billing alarm on day one.
  3. Build something smallHost a static website on S3, the classic first project.
  4. Come to a labJoin a Level 100 session and build with others.
  5. Share itGive a lightning talk on what you learned.
